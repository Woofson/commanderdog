          About CommanderDog
        

        
      

      

        
        

          
          
CommanderDog

          
Multi-Tab Web Commander - By Woofson

          

            v0.2.14 (Release)
            Rust + Axum + Tokio
            MIT Open Source
          

        


        
        

          CommanderDog brings the speed, keyboard ergonomics, and dual/quad-pane productivity of classic orthodox commanders (Midnight Commander, Total Commander, Norton Commander) directly to the web browser — powered by a lightweight Rust backend, multi-cloud storage drivers, real-time background transfer queues, and paranoid cryptographic data verification.
        


        
        

          

             System & Runtime Architecture
          

          

            
Author: Bolt J Woofson

            
Contact: bolt@boop.no

            
Backend: Rust 2021 (Axum 0.7)

            
Auth Engine: Linux PAM + SQLite RBAC

            
Terminal: Native PTY (portable-pty)

            
Frontend: Vanilla JS + Prism + Mermaid

            
Repository: github.com/Woofson/commanderdog

            
License: MIT License

          

        


        
        

          

            🗂️ 1-to-4 Dynamic Panes
            
Single, Dual, Triple & Quad grid layouts

          

          

            🌐 Multi-Cloud & Mounts
            
SMB/CIFS, NFS, S3, SFTP, WebDAV, Proton

          

          

            ⚡ DeltaCopy & TeraCopy
            
Bit-for-bit CRC32/SHA-256 integrity verify

          

          

            🔄 ConvertX Converter
            
Universal Image, Audio, Video & Document
