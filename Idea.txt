CommanderDog.

Quad pane file browser for web.

Must support WebDAV, ssh/sftp, and drag and drop easily between panels.
Like Next Explorer and XYPlorer smashed together and added two more panels.
Panels have to be toggleable ofc, so users can decide from 1 to 4 panels.
Easy drag-and-drop, as well as mc/*commander keybinds and right click context menu which is also user-customizable.

Support for scripting and some tools included, like compare/diff for easy comparison of folders. Amount of files/folders, size etc.
Some can be paranoid of file handling.

Support for most file archiving and file compression tools. Zip, 7z, rar, tar.bz/bz2 tar.gz etc.

Customizable right-click-context menu.
Native built in simple dual panel text-editor and markdown editor/reader with mermaid and color support.
Built in conf.d -directory reader, merging the conf.d configfiles together.
Comparison/diff of files.
Themes support, but charcoal/warm yellow/amber dark theme as default.

Must look as tidy and neat and be as responsive as Next Explorer.
Multi-user support, native linux users and/or own built-in user-database.
Run in Docker/LXC.
